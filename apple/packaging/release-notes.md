## Install

1. Download "Inventory Tracker for Mac" below and open it.
2. Drag Inventory Tracker into Applications.
3. Open it from your Applications folder.

The app is not notarized by Apple yet, so macOS shows a security warning the first time. If it won't open, go to System Settings, then Privacy & Security, and choose Open Anyway.

After that, the app updates itself. When a new version is ready, it asks, and you click Install Update.
